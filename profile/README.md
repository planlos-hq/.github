## Was ist PlanLos?

PlanLos plant die Lehrveranstaltungen einer Hochschule über die Woche. Kurse werden Zeitslots,
Räumen, Lehrenden und Studiengruppen zugeordnet. Dabei erkennt PlanLos Raum- und
Ressourcenkonflikte sowie Verstöße gegen Zeitwünsche von Lehrenden.
